# Contributing

Read `AGENTS.md` and `docs/WORKFLOW.md` before making changes.

The short version:

- Keep `main` stable.
- Use one `codex/<type>-<short-name>` branch per feature.
- Make small, focused commits.
- Run the relevant checks before pushing.
- Use European Portuguese (`pt-PT`) for all default learning content.
- Do not merge until the feature is complete and approved.
